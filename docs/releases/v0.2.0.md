# Ebira 0.2.0

Ebira searches local Claude Code and Codex conversation logs. This release adds
`ebira ask`, which answers a question about past work from the records, with
quotes checked against them.

- `ebira ask "<question>"` chooses search strings, screens what it finds, reads
  the records around the best of it, and answers with quotes, each checked
  against the records and cited by source reference. It uses Anthropic's API by
  default, or OpenAI, Google Gemini, OpenRouter, or any server that speaks the
  OpenAI Chat Completions API, under your own key. With the default models a
  question costs about $0.35; `--quick` costs about a tenth.
- `ebira ask-setup` opens a page on this computer to choose the service, check
  its key, and choose the models; `ebira ask` then uses them by itself.
- `ebira ask-usage` sums what `ask` has spent.
- `ebira sessions` lists the conversations: when each ran, where, how much you
  said, and how it began.
- `said` and `search` find several texts in one pass (repeat `--query`).
- Text views name the time zone of every time they show.
- Codex logs compressed with Zstandard (`.jsonl.zst`) are read, and a log moved
  to another folder keeps its source id.
- Claude Code's interrupt marks, Codex's message wrappers, and Codex's imported
  conversations are no longer taken for the person's words.

See [CHANGELOG.md](https://github.com/burutofosu/ebira/blob/v0.2.0/CHANGELOG.md)
for the full list.

## Upgrading

The first `ebira sync` after the update rebuilds the corpus from the original
logs under the new reading rules. Source ids are kept, so references made before
the update still read.

## Install

From source, with Rust 1.89 or later:

```sh
cargo install --locked --git https://github.com/burutofosu/ebira --tag v0.2.0
ebira sync
```

For a binary archive, extract it and put `ebira` or `ebira.exe` on `PATH`.
SHA-256 checksums for both archives are listed in `SHA256SUMS.txt`.
The archives include the license, README, example transcript, and agent skills.

## Agent skills

- Claude Code: copy the individual directories from `skills/claude` into `~/.claude/skills`.
- Codex: copy the individual directories from `skills/codex` into `~/.agents/skills`.

Keep each skill's `SKILL.md` and supporting files together. These locations
follow the [Claude Code skills guide](https://code.claude.com/docs/en/skills)
and the [Codex skills guide](https://learn.chatgpt.com/docs/build-skills).

## Compatibility and data

The package workflow builds Linux x86-64 and Windows x86-64 binaries, the
platforms verified for this release. The Linux build uses Ubuntu 22.04 and
glibc; it does not target musl-based distributions such as Alpine.

The binaries are unsigned.
Windows Smart App Control may block unsigned executables.

Keep the corpus and the original logs private. Ebira reads them locally; only
`ebira ask` sends anything out: the question and the text of the records it
reads, to the API you choose. Claude Code and Codex log format changes may
require an Ebira update.
