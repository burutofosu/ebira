# Ebira 0.3.0

`ebira ask` finds more, and says so when what it finds does not settle the question. Both
changes came out of the new evaluation in `evals/`: thirty questions about made-up logs,
with the answers known.

- Each search string is also searched with a space and with none between Latin letters or
  digits and Japanese, in the same pass: `csv取り込み` finds `CSV 取り込み`. Japanese is
  written both ways, and the search matches literally.
- When none of the records found is judged relevant, `ask` no longer returns an empty
  answer. It says first that the records found do not settle the question, with the
  strings searched and how many records they found, and answers from the closest of them,
  read with the records around them.
- `evals/` holds the thirty questions, five for each of six things that are hard about
  reading a history with agents, with a runner and a guide for judging the answers. On
  them the default models now make all the key points (93% in 0.2.1) and `--quick` 90%
  (84%), with no answer mistaken.

The result of `ebira ask` has a new field, `not_settled`, and a new disposition,
`nothing_relevant`; a program that reads the result may need updating.

See [CHANGELOG.md](https://github.com/burutofosu/ebira/blob/v0.3.0/CHANGELOG.md)
for the full list.

## Upgrading

The corpus stays as it is: no rebuild is needed.

## Install

From source, with Rust 1.89 or later:

```sh
cargo install --locked --git https://github.com/burutofosu/ebira --tag v0.3.0
ebira sync
```

For a binary archive, extract it and put `ebira` or `ebira.exe` on `PATH`.
SHA-256 checksums for both archives are listed in `SHA256SUMS.txt`.
The archives include the license, README, changelog, example transcript, and
agent skills.

## Agent skills

- Claude Code: copy the individual directories from `skills/claude` into `~/.claude/skills`.
- Codex: copy the individual directories from `skills/codex` into `~/.agents/skills`.

Keep each skill's `SKILL.md` and supporting files together. These locations
follow the [Claude Code skills guide](https://code.claude.com/docs/en/skills)
and the [Codex skills guide](https://learn.chatgpt.com/docs/build-skills).

## Compatibility and data

The package workflow builds Linux x86-64 and Windows x86-64 binaries, the
platforms verified for this release. The Linux build uses Ubuntu 22.04 and
glibc; it does not target musl-based distributions such as Alpine.

The binaries are unsigned.
Windows Smart App Control may block unsigned executables.

Keep the corpus and the original logs private. Ebira reads them locally; only
`ebira ask` sends anything out: the question and the text of the records it
reads, to the API you choose. Claude Code and Codex log format changes may
require an Ebira update.
