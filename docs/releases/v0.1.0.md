# Ebira 0.1.0


Ebira searches local Claude Code and Codex conversation logs.

- `ebira sync` builds a local corpus and picks up new records on later runs.
- `ebira said` lists your messages, with filters for session, project, text, and date.
- `ebira resume --session <id> --brief` shows recent messages, replies, and tool calls.
- `ebira search` matches literal text. `--raw` searches the original records.
- `ebira context` reads the original record behind a result and nearby records.

## Install

From source, with Rust 1.89 or later:

```sh
cargo install --locked --git https://github.com/burutofosu/ebira --tag v0.1.0
ebira sync
```

For a binary archive, extract it and put `ebira` or `ebira.exe` on `PATH`.
Each archive has a SHA-256 checksum file. The archives include the license,
README, example transcript, and agent skills.

## Compatibility and data

The package workflow builds Linux x86-64, Windows x86-64, and macOS binaries
for Apple Silicon and Intel. The Linux build uses Ubuntu 22.04 and glibc;
it does not target musl-based distributions such as Alpine.

The binaries are unsigned. The macOS binaries are not notarized.
Windows Smart App Control may block unsigned executables.

Keep the corpus and the original logs private. Ebira reads them locally.
The corpus can be rebuilt from the original logs. Claude Code and Codex log
format changes may require an Ebira update.
